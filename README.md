# tkn-group-website
Site web TKN Technics (TKN Group SRL) : pages HTML statiques, une feuille de style (`css/tkn.css`) et un script (`js/main.js`).

## Assets et licences
- Illustrations des métiers, de l'accueil et de la page Équipes : dessins vectoriels originaux créés pour ce site, intégrés en SVG dans les pages. Aucune image externe.
- Image de partage `assets/og-tkn.png` : composée à partir de ces illustrations et du logo.
- Logo TKN Technics (`assets/tkn-logo*.png`, `assets/tkn-badge.png`) : fourni par l'entreprise. `tkn-logo-128.png` en est une copie réduite, dessin inchangé.
- Polices Archivo et Instrument Sans : Google Fonts, licence SIL Open Font License 1.1.
- Photographies : aucune. Les deux photos d'ambiance précédentes, d'origine non documentée, ont été retirées.
